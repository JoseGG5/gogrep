First project to use golang. Just a small grep clone with minimal functionalities:

1. Search literal text in a given file and print lines ✅
2. Print line number with -n flag ✅
3. Ignore capital letters and lowercase with -i flag ✅
4. Search on multiple files with goroutines ✅
5. Search recursively on a directory with -r ✅
6. Support regex with -E
